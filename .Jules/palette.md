## 2024-05-18 - Yield Dashboard Empty State
**Learning:** Empty states in dynamic content areas (like the yield history list) shouldn't just be unstyled text. Using the existing card styling (`yield-hist-card`) with a dashed border provides a consistent, clear, and visually integrated empty state that guides the user.
**Action:** When adding new empty states, always mirror the styling of the populated content (e.g., using the same wrapper class with dashed borders and lower opacity) to maintain layout consistency and visual hierarchy.
