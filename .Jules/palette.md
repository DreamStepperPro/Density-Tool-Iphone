## 2024-05-30 - [Loading States for Async Auth]
**Learning:** Adding explicit "loading" or "verifying" states to authentication buttons (like `loginWithPin`) provides critical feedback that the system is processing the request, reducing the likelihood of users mashing the button multiple times and firing off redundant, potentially error-inducing network calls.
**Action:** Always implement disabled/loading states for asynchronous UI interactions, ensuring the button's original active state is securely restored across all potential Promise resolution paths (success and `.catch` errors) to prevent the UI from becoming permanently locked.
