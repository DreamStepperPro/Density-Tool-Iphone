## 2026-06-22 - Missing Loading State on PIN Login Button
**Learning:** For actions like PIN entry that trigger async authentication (Firebase), it is essential to disable the submission button and provide text feedback (like "VERIFYING...") to prevent double-submissions and let the user know the system is working. If this isn't implemented properly, users may hit the button multiple times, causing race conditions or generating duplicate requests.
**Action:** Always wrap asynchronous authentication actions with a UI lock (disabling the submit button and showing a loading text indicator). Ensure to release the lock in both the `.then()` success block and all `.catch()` error handlers.
